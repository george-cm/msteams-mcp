## Traps learned

- **Windows `npm run` cuts multi-line arguments at the first newline**, drops later flags, still says `ok`. Use `--content-file` for message text; for anything else call `node node_modules/tsx/dist/cli.mjs src/cli.ts ...`.
- **`gh` without `--repo`** used to target upstream. Always pass `--repo george-cm/msteams-mcp`.
- **Never `npx`** for tools not in `package.json`.
- **Upload root:** set `TEAMS_MCP_UPLOAD_DIR` for files under `.worktrees` or `.tmp`.
- **Teams session expires overnight:** a plain `login` renews it silently.
- **Known local test failure:** 1 Windows-only file-mode test (`expected 438 to be 384`) fails on `main`; anything else failing is real.
